# 📒 Gerenciamento de Relacionamento com Clientes

Um CRM simples e visual feito com HTML, CSS e JavaScript puro, que permite cadastrar, visualizar e excluir contatos — com persistência de dados via `localStorage`.

---

## ✨ Funcionalidades

- **Cadastro de contatos** com nome, empresa, departamento e informações adicionais
- **Status do contato** selecionável: Ativo, Ausente ou Inativo (com indicador visual colorido)
- **Avatar gerado automaticamente** com as iniciais do contato e cor aleatória
- **Persistência de dados** — os contatos continuam salvos mesmo após recarregar a página
- **Exclusão de contatos** com botão individual por card
- **Interface responsiva** com formulário modal para adição de novos contatos

---

## 🖥️ Tecnologias

- HTML5
- CSS3 (animações, variáveis, flexbox)
- JavaScript (vanilla)
- localStorage (persistência de dados)
